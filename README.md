# Public reports

A static collection of explicitly shared reports, served at <https://ryoma0622.github.io/public-reports/>.

GitHub Pages publishes directly from the root of the `main` branch. There is no custom GitHub Actions workflow or application server. `.nojekyll` preserves the exported HTML and asset bytes.

Use **GitHub Pagesで公開** in the report viewer to review a static snapshot and publish it. Markdown and HMD-1 are rendered mechanically to HTML using the same viewer renderer. Existing images and audio accompany the selected report; generation, assistants and private Library data are not included. Report content is never automatically selected for publication.

Each report has a stable URL under `reports/`. Republishing updates that URL. Previously committed versions remain in the public Git history.
